Bash — Bourne Again Shell

Now let’s do Some Recon with the Help of BASH

Subdomain Enumeration

  1. One-liner to find the subdomains:
while read sub; do if host “$sub.example.com” &> /dev/null; then echo “$sub.example.com”; fi; done < subdomains_wordlist.txt
~tomnomnom

2. Automating Stuff with the help of tools:
Note: these tools should be already installed in your system
Check out my previous blog post to install and use all the tools

Recon like you owns it!

##!/bin/bash
#starting assetfinder
assetfinder --subs-only $1 | tee -a domains.txt
#starting amass
amass enum --passive -d $1 -o domains
#removing duplicate entries
sort -u domains -o domains
#filtering the domains
cat domains | filter-resolved | tee -a domains.txt
rm domains
#checking for alive domains
echo "\n\n[+] Checking for alive domains..\n"
cat domains.txt | ~/go/bin/httprobe | tee -a alive.txt
Save the above script with subenum.sh and give it executable permission
chmod +x subenum.sh

In the above script, we have used amass and assetfinder for subdomain enumeration, then sort to remove the duplicate entries after it I have used filter-resolved (another get tool by tomnomnom) to resolve the domains and to check how many domains are actually alive, for that we have used a tool called httprobe by tomnomnom and saved the alive domains in a different file called alive.txt.

Next Comes Subdomain Takeover

It starts with checking the CNAME of subdomains

host -t CNAME subdomain.example.com

Having a lot of targets to scan.

Checking every subdomain manually takes time.
The following one-liner shortens that process:

One Liner to do it is:

cat domains.txt | xargs -n 1 -I{} host -t CNAME {}

For speeding things up pipes give you some parallelization for free and xargs can run things in parallel

Next, We’ll Build a Script to Find CORS Misconfigurations

So this is the easiest way to find the CORS misconfiguration

You can download this script from here: https://raw.githubusercontent.com/tomnomnom/dotfiles/master/scripts/acao

Give it executable permission by chmod and run it:

./acao <subdomain_filename>
